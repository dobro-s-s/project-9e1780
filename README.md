# Тренируем Логику

Создай адаптивное веб-приложение на русском языке под названием «Тренируем логику».

Это интерактивный тренажёр для детей 8–10 лет.

Пока создай только стартовый экран:

Заголовок «Тренируем логику».

Приветствие: «Привет! Готов проверить свою сообразительность?»

Короткая инструкция: «Тебя ждут интересные задания на внимание и логику».

Кнопка «Начать».

Дизайн: яркий, современный, дружелюбный, но без визуального перегруза. Крупные элементы, хорошо читаемый текст. Приложение должно удобно отображаться на телефоне, планшете и компьютере.

После нажатия на кнопку «Начать» пока показывай экран-заглушку с текстом «Здесь будут задания».

Не добавляй регистрацию, базу данных и авторизацию. Сделай кнопки работающими.
